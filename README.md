# N.E.G.S: Заполярье

Тактический 3D-шутер от первого лица на Three.js. Сержант **Кей**, командир отделения подразделения **N.E.G.S** (Northern Extremist Groups Suppression), проходит цепочку специальных операций в Заполярье, чтобы добраться до **Лойда Кранди** — самого разыскиваемого преступника мира, главы преступного мира и командира группировки войск **«Дентер»**.

## Запуск

Сборка уже лежит в `dist/game.js`, поэтому достаточно открыть `index.html` в браузере (Chrome/Edge/Firefox с WebGL2).

Если браузер блокирует захват мыши у локального файла, запустите любой статический сервер из корня проекта:

```bash
npm run serve          # python3 -m http.server 8080 → http://localhost:8080
```

Разработка:

```bash
npm install
npm run dev            # esbuild --watch + сервер на http://localhost:8000
npm run build          # минифицированная сборка в dist/game.js
npm run single         # однофайловая версия dist/negs-zapolyarye.html (удобно пересылать)
```

## Главная фишка: реалистичная стрельба

* **Никакой прицельной точки.** На экране нет перекрестия ни при стрельбе от бедра, ни при прицеливании.
* **Механические прицелы** (АК-74М, АКМ, ПКМ, РПГ-7В без оптики, ГП-25) — это трёхмерные целик и мушка. Линия прицеливания проходит через прорезь целика и вершину мушки, а ствол повёрнут относительно неё на угол прицеливания для выбранной установки прицела (П, 1–10 у АК; 1–15 у ПКМ; 2–5 у РПГ; 50–400 м у квадранта ГП-25). При поднятом целике видно, как поднимается планка, а у ГП-25 на больших дальностях автомат заметно «задирается» вверх.
* **Оптические прицелы** — ПСО-1 (СВД, 4×, маховичок 1–10, угольники на 1100–1300 м, дальномер на 1,7 м), 1П78 (2,8×), ПГО-7 (РПГ, 2,7×, марки 2–5, шкала боковых поправок, дальномер на 2,7 м), ПП-61АМ (башня МТ-ЛБ). Все марки сеток строятся **по баллистическому решению того же боеприпаса**, а дальномерные шкалы — по реальной угловой высоте цели. Бинокль Б-8 с угломерной сеткой в тысячных.
* **Пуля вылетает из дульного среза по оси ствола.** Раскачка (дыхание, тремор, усталость, подавление), инерция оружия при повороте и отдача физически смещают ствол — пуля летит туда, куда он смотрит. Shift при прицеливании — задержка дыхания.

## Баллистика

`src/physics/ballistics.js` — одна модель для игры и для таблиц стрельбы:

* точечная масса, интегрирование методом средней точки (шаг 1/240 с);
* сопротивление воздуха по стандартным функциям **G7/G1** и баллистическому коэффициенту; плотность воздуха и скорость звука считаются по температуре и давлению (мороз ощутимо «роняет» пулю);
* **ветер** (боковой снос), **деривация** (формула Литца), **сила Кориолиса** для широты 69°;
* **реактивная граната ПГ-7ВМ**: стартовый заряд 140 м/с → маршевый двигатель до ~300 м/с, самоликвидатор 4,6 с; при боковом ветре оперённая граната на активном участке **разворачивается носом к ветру и уходит против ветра**;
* **ВОГ-25** с навесной траекторией и взведением на 10 м, ручные гранаты Ф-1 с отскоками;
* прицелы пристреляны в «нормальных условиях» (−20 °C), а летит пуля в условиях миссии — в −36 °C поправка нужна по-честному;
* пробитие деревянных стен, рикошеты от металла/бетона/льда по касательной, бронежилеты и шлемы, бронирование техники по проекциям, кумулятивное действие ПГ-7.

## Штаб

В 3D-штабе «Полярный Лис» можно ходить (WASD) и взаимодействовать (E):

* **стенд «Таблицы стрельбы и траектории»** на стене (графики и таблицы рисуются из расчёта) — подробный просмотр: дальность, прицел в тысячных, снижение, время полёта, скорость, энергия, снос ветром 10 м/с, деривация, поправка на −40 °C, дальности прямого выстрела по головной/грудной/ростовой фигурам, графики траекторий и скорости для каждого снаряда (5,45 7Н10, 7,62×39, 7,62×54R 7Н1 и ЛПС, ПГ-7ВМ, ВОГ-25, Ф-1);
* **карта операций** — выбор задания и брифинг (погода, ветер, температура, видимость);
* **стенд личного состава** — 8 бойцов с характеристиками (меткость, реакция, стойкость под огнём, выносливость), биографией и опытом; на задание берётся до 6;
* **оружейная** — выбор оружия Кея и РПГ-7В;
* **автопарк** — бронеавтомобиль «Тигр», ВАЗ-2121 «Нива», МТ-ЛБ.

## Операции

0. **Полигон «Норд»** — мишени на 50–1000 м, остовы для РПГ, валы для ГП-25, флажки ветра, корректировщик докладывает отклонение каждого попадания; пирамида со всем оружием; можно погонять всю технику.
1. **Тихая станция** — зачистка метеостанции «Полярная-7», жёсткий диск ретранслятора.
2. **Белый перевал** — засада на колонну «Дентера» (две «Нивы» + МТ-ЛБ с десантом) в снегопад.
3. **Глаз Севера** — снайперы на вышках на 900 м, сильный боковой ветер, антенна РЛС, отражение контратаки на технике.
4. **Ледяной порт** — полярная ночь и северное сияние, топливные цистерны, документы логиста, отход под подкрепление.
5. **Объект-17** — прорыв периметра (МТ-ЛБ у ворот), ликвидация Лойда Кранди до того, как он уйдёт к катеру.

## Противник

ИИ (`src/ai/brain.js`) — не «тир», а взаимодействующие бойцы:

* зрение с накоплением обнаружения (дистанция, стойка, движение, вспышки выстрелов ночью, белый камуфляж), слух (выстрелы, взрывы), реакция на попадания и пролёты пуль;
* память о противнике и **обмен данными внутри группы** по рации с задержкой;
* выбор **укрытий** (проверка защиты от угрозы и возможности вести огонь), цикл «укрылся — выглянул — отстрелялся», перезарядка в укрытии, смена скомпрометированного укрытия;
* **огонь на подавление** по последнему известному положению, пока патронов больше половины; когда БК заканчивается — **режим экономии**: только видимые цели, одиночными, с долгим прицеливанием и большей точностью; при пустом БК — подбирают патроны у убитых;
* баллистически корректная стрельба: оценка дальности с ошибкой, угол возвышения по своей «таблице», упреждение, разброс по навыку, подавлению и усталости от очереди; огонь не ведётся, если на линии свой;
* **фланговые манёвры** (один боец обходит, остальные прижимают огнём), ручные гранаты по засевшим, гранатомётчики работают по технике, снайперы на вышках, пулемётчики;
* колонны на технике спешиваются при обстреле, стрелок МТ-ЛБ работает из ПКТ.

## Своё отделение

Бойцы следуют клином, сами занимают укрытия у назначенной позиции, ведут огонь, медик подходит к раненым, снайпер по запросу из бинокля (ЛКМ) называет дальность. Приказы: **F** — за мной, **H** — стоять, **T** — выдвинуться в точку взгляда, **V** — огонь на подавление по точке взгляда. При посадке командира в машину отделение рассаживается само; в МТ-ЛБ один боец садится за ПКТ.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, Shift, Space | движение, бег, прыжок |
| C / Z | присесть / лечь |
| ЛКМ / ПКМ (удерживать) | выстрел / прицеливание через целик-мушку или оптику |
| колесо (при прицеливании), [ ], PgUp/PgDn | установка прицела |
| R / B | перезарядка / режим огня |
| X / O | ГП-25 / оптика ↔ механика РПГ |
| 1 2 3 4 | автомат, гранатомёт, гранаты, бинокль |
| K | перевязка |
| E | взаимодействие, посадка в технику |
| F H T V | приказы отделению |
| Tab / M / Esc | отделение / карта / пауза |

Техника: W/S — газ/тормоз, A/D — руль, Space — тормоз, C — камера, 1/2 — водитель/стрелок, E — выход.

